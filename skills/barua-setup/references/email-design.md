Each Barua preview is a public HTML email. If your browsing tool skips it, fetch the linked HTML directly without credentials.

## Adapt and preview

- Keep the workspace's approved layout, voice, link destinations and standing feedback. Use an example for structure. Write original wording and use only assets supplied for this brand.
- Give an action email one prominent next step. In a receipt or status update, make the fact people came to find visible before the action. Within a sequence, keep the same visual cues and give each later email its own reason to exist.
- Use text for dates, amounts and status so the email still works with images hidden. A visible number needs a declared source. If an optional name or image is absent, the reader should still recognize the item or next step from the approved fallback.
- Open the actual rendered preview in each requested language. Check a narrow screen, read the first lines with images hidden, and verify the button's label against its destination. Revise through the [writing workflow](writing.md) and its existing review step.
